# Va-de-Bike

O **VáDeBike** é um projeto acadêmico que consistiu no desenvolvimento de um site responsivo para aluguel e devolução de bicicletas em diferentes pontos da cidade. Seu objetivo é facilitar a mobilidade urbana, permitindo que os usuários localizem bicicletários, consultem a disponibilidade de bicicletas e realizem aluguéis.

## Funcionalidades
- Cadastro e login de usuários.
- Consulta de bicicletas disponíveis.
- Localização de bicicletários por mapa.
- Aluguel e devolução de bicicletas.
- Histórico de aluguéis.
- Recomendação de bicicletários próximos.
- Previsão dos horários de maior procura.
